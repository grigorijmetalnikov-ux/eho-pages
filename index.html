ЭХО

Программа для ведущих праздников: игра-шоу, где гости переозвучивают сцены из фильмов и мультфильмов. Служебная часть (лицензии, выдача раундов, админка) работает на собственном сервере владельца.

Доступ к Google

Сервер ЭХО подключается к Google Диску только владельца и запрашивает лишь право drive.file: он видит и меняет только файлы, которые создал сам, — свою папку «ЭХО» с зашифрованными резервными копиями базы и таблицей выдачи раундов. Остальные файлы на Диске, почта и другие данные аккаунта ему недоступны. Отозвать доступ можно в любой момент: myaccount.google.com/permissions.

About (English)

“EHO” is a party game show for event hosts. Its back office runs on the owner's own server. The server connects only to the owner's Google Drive with the drive.file scope, to store encrypted database backups and a delivery log spreadsheet in a folder it creates. See the privacy policy.
