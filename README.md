# eho-pages — страницы для Google OAuth

Две статические страницы на GitHub Pages для сервера ЭХО (код — в приватном репозитории `eho`):

- `index.html` — что это и какой доступ к Google просит сервер;
- `privacy.html` — политика конфиденциальности.

Зачем: Google не переводит OAuth-приложение (проект `exo-save`) в режим «In production» без этих ссылок; в «Testing» доступ к Диску слетал бы каждые 7 дней.

Репозиторий **публичный** (бесплатный GitHub Pages работает только из публичных) — здесь только эти страницы: никакого кода, данных, ключей и личных контактов.
